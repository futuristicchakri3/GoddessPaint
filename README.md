
# GoddessPaint - Python Turtle Drawing

A Python project that draws a goddess image using Turtle Graphics and OpenCV.

## Features
- Converts an image to grayscale.
- Detects image contours using OpenCV.
- Draws the contours with Python Turtle.
- Creates a black-and-white drawing effect.

## Requirements
- Python 3
- OpenCV
- NumPy
- Turtle Graphics

## Installation

Install the dependencies:

```bash
pip install -r requirements.txt
```

## How to Run

Make sure `mataji.jpg` is in the same folder as `Goddess.py`.

Run:

```bash
python Goddess.py
```

## Technologies Used
Python, OpenCV, NumPy, Turtle Graphics
